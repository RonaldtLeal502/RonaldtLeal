### 📞 02. Auditoría Analítica de Sábanas Telefónicas (FarFay Group)
**Rol:** Analista de BI & Data Engineer  
*Extracción de valor financiero a partir de registros masivos de telecomunicaciones.*

* **El Reto:** Procesar más de 50,000 registros mensuales dispersos para identificar fugas de capital.
* **La Solución:** Implementé un pipeline de limpieza con **Python (Pandas)** y modelado en **Power BI** utilizando **DAX avanzado**.
* **Impacto:** Identificación de patrones de gasto ineficiente, sugiriendo un ahorro potencial del **12% en costos operativos**.
* **Keywords:** `ETL`, `Análisis de Anomalías`, `Optimización de Costos`.
