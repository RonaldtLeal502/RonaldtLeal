### 🔧 Sistema de Gestión de Materiales | Laboratorio de Electrónica
**Universidad del Caribe** | *Full Stack Development & Database Design*

Plataforma web integral que revolucionó la gestión de inventario del laboratorio, eliminando procesos manuales y proporcionando trazabilidad completa de activos.

**🎯 Problema Resuelto:**
- Control manual propenso a errores y pérdidas de componentes
- Ausencia de registro histórico de préstamos

- Diseño e implementación de base de datos relacional normalizada
- Desarrollo de aplicación web responsive con React y Material UI
- Sistema de autenticación y gestión de roles de usuario
- Dashboard en tiempo real para seguimiento de inventario

**📊 Resultados:**
- ✅ Reducción del 100% en registros manuales
- ✅ Trazabilidad completa del ciclo de vida de componentes
- ✅ Mejora significativa en la experiencia del usuario

### 📊 Optimización de Costos Telefónicos | FarFay Group
**Business Intelligence & Data Analytics** | *Cost Reduction Initiative*

Proyecto de análisis de datos a gran escala enfocado en identificar oportunidades de optimización de costos operativos mediante el procesamiento inteligente de sábanas telefónicas.

**🎯 Desafío:**
- Análisis manual de miles de registros telefónicos mensuales
- Falta de visibilidad sobre patrones de consumo y costos ocultos
- Ausencia de indicadores clave para la toma de decisiones

**💡 Solución Desarrollada:**
- Pipeline automatizado de ETL para limpieza y transformación de datos
- Modelado dimensional para análisis multivariable
- Dashboards interactivos con KPIs personalizados por área
- Sistema de alertas automáticas para anomalías de consumo

**📊 Impacto Medible:**
- 📉 Identificación de oportunidades de ahorro del 20-30%
- 📈 Visibilidad completa de patrones de uso por departamento
- ⚡ Reducción de 15 horas/mes en procesamiento manual
- 🎯 Información accionable para negociación con proveedores

**Tecnologías:** `Python` `Pandas` `Power BI` `SQL` `DAX`
